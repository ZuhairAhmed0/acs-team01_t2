# 💻 محفظة الوقود الرقمية — الواجهة الأمامية (Fuel Wallet Frontend)

تطبيق الويب التفاعلي لمنصة **محفظة الوقود الرقمية** المبني باستخدام **React 19**، **TypeScript**، **Vite 8**، **Tailwind CSS**، **Clerk React SDK**، و **TanStack React Query**.

---

## 🚀 التشغيل السريع

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل خادم التطوير (http://localhost:5173)
npm run dev

# 3. فحص الكود وبناء نسخة الإنتاج
npm run lint
npm run build
```

---

## ✨ صفحات ومكونات التطبيق

- **الرئيسية (`/`)**: بطاقة إجمالي الرصيد، المحفظة الرئيسية، محافظ المحطات المخصصة، المحطات المشاركة، وآخر العمليات المالية.
- **المحافظ (`/wallets`)**: استعراض المحفظة الرئيسية (برقم تعريفي مختصر مكون من 6 أرقام مثل `#104829`) ومحافظ المحطات وكشف الحساب المحاسبي (`Ledger Statement`).
- **المحطات (`/stations`)**: البحث والتصفية حسب المدينة، إضافة محطة جديدة، تعديل بيانات المحطة، أو حذفها.
- **شراء وقود (`/pay`)**: الدفع الفوري في المحطة وإصدار إيصال يحتوي على رمز التحقق السداسي (`6-Digit Verification Code`).
- **تحويل رصيد (`/transfer`)**: التحويل الفوري بين المحفظة الرئيسية ومحافظ المحطات أو من محطة لأخرى.
- **السجل (`/transactions`)**: سجل المعاملات مع التصفية حسب النوع والحالة والتصفح بالمؤشر (`Cursor Pagination`).
- **لوحة المشغل (`/operator`)**: ملخص إيرادات المحطة اليومية، تغيير المحطة المسندة للمشغل، التحقق من الرمز السداسي للسائق، وتحديث حالة الازدحام.
- **لوحة الإدارة (`/admin`)**: محاكاة حالة بوابة البنك (`UP / DOWN`)، تشغيل مطابقة القيد المزدوج (`Reconciliation`)، إدارة المحطات، وتجميد/تنشيط المستخدمين.
